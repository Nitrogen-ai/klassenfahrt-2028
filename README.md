# Klassenfahrt 2028 – vier Ziele im Vergleich

Übersicht der CTS-Angebote Hamburg, Prag, Polen (Krakau & mehr) und Danzig für die Klassenfahrt 19.–23.06.2028.

- Seite: https://nitrogen-ai.github.io/klassenfahrt-2028/
- Inhalte in `build.py` (Liste `ZIELE`), dann `python3 build.py --kacheln` – erzeugt index.html, die vier Zielseiten und die Plickers-Kacheln `kacheln/*.png` (1200 × 1200 px).
